## 开源基础

选择 [AirPodsDesktop](https://github.com/SpriteOvO/AirPodsDesktop)，因为它已有 Windows 原生蓝牙设备枚举、Apple BLE 广播解析、分耳和充电盒电量、动画弹窗及托盘功能。相比调研到的 [MagicPodsCore](https://github.com/steam3d/MagicPodsCore)，前者直接面向 Windows，而后者主要面向 Linux。

上游固定版本：`56b04001f75044dbd15507303a9438c71e93c6e4`，GPL-3.0-or-later。完整应用源码与许可证保存在 `airpods-desktop/`，来源说明见 `UPSTREAM.md`。保留原作者的版权和资源许可证；这是改进版，不是官方发行版。未复制上游自动发布流水线。

## 实际改进

| 场景 | 上游行为 / 问题 | 本版实现 |
| --- | --- | --- |
| 已连接，但尚未收到电量 | 主界面主要依赖电量状态更新，设备名可能仍是状态占位文字 | Windows 配对设备名称独立传入；显示“已连接 · 等待电量广播” |
| 超过约 10 秒没有广播 | 电量缓存丢弃沿用 Disconnected 事件，弹窗显示断开 | 弹窗使用独立 BatteryUnavailable 事件；清空电量，保持 Windows 报告的连接状态 |
| Windows 报告断开 | 依赖电量生命周期更新界面 | 直接订阅 OS 连接回调，立即清空电量并保留名称 |
| 断开后迟到的广播 | 容易在后续扩展中混用广播与连接状态 | 状态机拒绝用广播建立连接；界面不缓存断开期间的电量 |
| 缺失某一路电量 | 隐藏电量控件，含义不直观 | 固定左耳、右耳、充电盒三列；缺失显示“—”，真实 0% 仍显示 0% |
| OS 连接成功 | 弹窗主要由充电盒开盖事件触发 | 增加连接成功时弹出，继续保留上游开盖动画与自动收起 |
| 设备切换 | 名称与广播数据相互依赖 | 重新绑定清除旧名称、连接信息和电量，避免沿用旧设备数据 |
| 名称包含 Bluetooth 或 Find My | 可能将自定义名称丢弃或删除其中内容 | 不再过滤含 Bluetooth 的自定义名称；只移除末尾的 Find My 服务后缀 |
| 电量扫描器故障 | 不易区分连接故障和电量读取失败 | 显示“已连接 · 电量扫描不可用”，不把扫描失败当成 OS 断开 |
| 中文界面 | 缺少新增状态的翻译 | 补充简体及繁体中文状态、三路标签与电量说明 |
| 评估版更新 | 默认自动查询上游正式版本 | 不启动自动更新检查，避免自动提示覆盖修改版 |

界面沿用上游圆角卡片、设备动画、深浅主题、多屏定位和 DPI 适配。弹窗从 320×300 调整为 320×340，为独立状态行、三路标签及电量说明留出空间。设备名仍使用纯文本并支持长名称省略及完整名称提示。Windows 编译统一启用 `/utf-8`，避免不同系统代码页影响新增状态文字。

本次对连接与电量分离的改进作用于弹窗；托盘及任务栏继续保留上游的电量可用性语义，未声称它们的状态展示也已重做。

## 如何评估

打开同目录的 `preview.html`，无需安装或联网。可修改设备名、切换深浅主题，检查六种状态：正常电量、等待广播、断开、充电盒无数据、低电量充电、扫描器故障；也可关闭和重播弹窗。

**效果稿全部为模拟数据，不扫描蓝牙。** 它展示信息布局及状态措辞，不代表已验证 Windows 原生渲染、设备动画或硬件读取。原生 Qt UI 及数据处理修改在源码中，可继续构建验证。

## 兼容性与待验收项目

- 本版沿用上游 **Windows 11 x64** 路线，不支持 ARM64。需要蓝牙适配器支持 BLE 广播监听；先通过 Windows 设置配对 AirPods，再在程序内绑定设备。
- “已连接”来自 Windows 蓝牙设备状态，不代表当前音频输出一定选中了 AirPods。
- AirPods 电量来自 Apple 广播，而非适用于所有耳机的标准电量接口。广播可能间歇出现，电量通常为粗粒度估算；合盖后充电盒数据可能无法持续读取。固件、型号、驱动都会影响可用性。
- 上游对随机 BLE 地址的设备关联仍采用型号、信号强度及历史电量等启发式方法。同型号多设备靠近时存在错误关联的可能，本次没有宣称解决 Apple 隐私地址带来的唯一身份关联问题。
- 保留上游型号表不等于所有型号均已实测；尤其较新型号需逐一核验。
- 后续 Windows 验收应覆盖：首次绑定、自定义设备名、连接即弹出、开盒/合盒、左右耳及充电盒充电、真实 0%、一耳缺失、广播超时但音频仍连接、断开重连、关闭蓝牙、睡眠唤醒、多个同型号设备，以及 100%/125%/150%/200% 缩放下的原生 UI。

用户已批准进入实机测试；Windows 云端构建已通过，下一步由用户在测试电脑解压运行便携包。不会安装程序或设置开机启动。
